# 해상도별 출력 설정

원본 영상의 **세로 높이**에 따라 FPS 상한이나 원본 배수를 다르게 지정할 수 있습니다. 처음에는 꺼져 있으므로 기존 설정 파일을 그대로 사용하면 이전 출력 방식이 유지됩니다.

## 사용 방법

1. **보간 설정**에서 프레임 보간을 켭니다.
2. **출력 방식**을 **해상도별 설정**으로 바꿉니다.
3. 오른쪽 **해상도별 편집…**을 누릅니다.
4. **기본 출력**을 정하고, 다르게 처리할 해상도 구간의 **출력 설정**을 바꿉니다.
5. **저장**을 누른 뒤 영상을 다시 엽니다.

출력 방식 선택은 즉시 저장됩니다. 편집 창 안의 변경은 **저장**을 눌러야 반영됩니다. 편집을 취소해도 앞서 선택한 출력 방식까지 되돌아가지는 않습니다.

## 해상도 구간

구간은 영상의 가로나 이름이 아닌 원본 세로 픽셀 수로 나뉩니다. 각 영상에는 아래 한 구간만 적용됩니다.

| 화면의 구간 이름 | 원본 세로 높이 |
| --- | --- |
| 480p 미만 | 1–479 px |
| 480p 이상 | 480–719 px |
| 720p 이상 | 720–1,079 px |
| 1080p 이상 | 1,080–1,439 px |
| 1440p 이상 | 1,440–2,159 px |
| 2160p 이상 | 2,160–4,319 px |
| 4320p 이상 | 4,320 px 이상 |

예를 들어 **1920×800** 영상에는 **720p 이상**, **1920×1080** 영상에는 **1080p 이상** 설정을 적용합니다. ‘1080p 이상’ 행이 모든 더 큰 영상을 함께 지정하는 것은 아닙니다. 1440px부터는 다음 행을 사용합니다.

## 선택할 수 있는 출력

| 설정 | 동작 |
| --- | --- |
| 기본 설정 사용 | 편집 창 위쪽의 **기본 출력**을 따릅니다. |
| 최대 60 / 72 / 75 / 100 / 120 / 144 / 240 fps | 상한 안에서 가능한 가장 큰 원본 정수배로 보간합니다. |
| 원본 ×2 / ×3 / ×4 / ×5 | 원본 FPS에 선택한 배수를 적용합니다. |
| 보간 안 함 | 해당 구간은 원본 FPS로 재생합니다. |

**기본 출력**에는 FPS 상한 또는 원본 배수를 지정합니다. 구간별 행에서만 **기본 설정 사용**과 **보간 안 함**을 선택할 수 있습니다.

FPS 상한은 정확히 그 FPS로 맞추는 기능이 아닙니다. 예를 들어 25fps 영상에 최대 120fps를 지정하면 ×4인 100fps로, 24fps 영상에 최대 60fps를 지정하면 ×2인 48fps로 출력합니다. 원본 배수 ×3을 지정하면 25fps는 75fps가 됩니다.

## 다른 설정과의 관계

메인 화면의 **프레임 보간**, **보간할 원본 FPS**, **세로 해상도** 조건은 해상도별 설정에서도 계속 적용됩니다.

- 프레임 보간이 꺼져 있으면 모든 영상이 원본으로 재생됩니다. 기존 선택은 유지됩니다.
- 선택하지 않은 원본 FPS는 해상도별 출력과 관계없이 보간하지 않습니다. 원본 FPS를 하나도 선택하지 않으면 모든 영상이 원본으로 재생됩니다.
- 세로 해상도가 **1080p 이하**이면 세로 1080px까지만 보간합니다. 같은 **1080p 이상** 구간에 속하더라도 세로 1200px 영상은 제외됩니다. **1440p 이하**도 실제 세로 1440px를 기준으로 적용됩니다.

모든 구간을 사용하려면 세로 해상도를 **전체**로 선택합니다. 편집 창의 안내 문구에서 현재 적용 중인 조건을 확인할 수 있습니다.

## 저장, 취소, 되돌리기

**저장**은 기본 출력과 일곱 구간을 한 번에 저장합니다. 저장에 실패하면 창이 열린 채 오류 안내가 표시되므로 폴더 쓰기 권한을 확인한 뒤 다시 시도할 수 있습니다. 저장한 설정은 영상을 다시 열 때 적용됩니다.

**취소**, Escape 또는 창 닫기는 이번 편집을 버립니다. **모두 기본 설정**은 일곱 행을 **기본 설정 사용**으로 바꾸며, 위쪽의 기본 출력 값은 유지합니다. 이것도 저장 전에는 편집 중인 내용에만 반영되므로 취소할 수 있습니다.

메인 화면에서 출력 방식을 **FPS 상한**이나 **원본 배수**로 바꾸면 해상도별 적용이 꺼집니다. 저장했던 구간별 선택은 남아 있으므로 나중에 **해상도별 설정**을 다시 선택하면 재사용할 수 있습니다.

## 확인 범위

2026-10-14 기준으로 UI 빌드와 격리된 설정·레이아웃 자체 검사를 통과했습니다. 실제 WPF의 메인 화면, 비활성 상태, 편집 창의 기본·최소 크기와 150%·200% 래스터 배율을 검토했고 독립 마감 검토 결과는 **ship**입니다. 화면 캡처의 재생 수치와 설정은 검사용 예시입니다.

추가로 실제 네이티브 필터의 GPU 통합 검사 13개를 통과했습니다. 일곱 해상도 구간, 마스터 끄기·FPS 선택·높이 제한 우선 적용, 공통 모드 복귀, 잘못된 설정의 공통값 복귀, 기존 연속 탐색 수정을 확인했습니다. 시각·정수 출력 수·EOS·GPU 전달도 검사했습니다. 해상도 경계와 파서 단위 검사 및 기존 관련 CTest 6개도 통과했습니다.

`bin/NvofPotPlayer.ax`와 `bin/NvofControl` 실행 파일 묶음에 설치했으며 설치본 UI 자체 검사도 통과했습니다. 기존 최대 240fps 설정 및 `NvofTuning.ini`는 해시가 동일합니다. 새 모드는 자동 활성화하지 않으므로 설정 창에서 **해상도별 설정 → 해상도별 편집…**을 선택해 사용합니다.

물리 키보드 조작과 모니터 간 DPI 전환, 새 해상도 설정을 이용한 실제 팟플레이어 화면 확인은 이 검토에서 수행하지 않았습니다. 새 바이너리는 플레이어와 설정 창을 다시 실행하면 사용됩니다.
