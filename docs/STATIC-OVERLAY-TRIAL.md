# 0.3.1-overlay.1 — 고정 흰 그래픽 보완

이전 설치판 0.3.1-quality.1을 기준으로 F1 1:32의 고정 흰 제목과 코스 선에서 튀어나오는 밝은 조각을 줄인다. 초기에는 처리 비용 증가 때문에 보류했으나, 사용자가 약 7%의 추가 비용을 허용하면 시험할 가치가 있다고 판단해 로컬 시험판으로 채택했다. 전체 해결이나 다른 모든 영상에서 손실이 없다는 보장은 아니다.

## 처리

기존 고정 영역 마스크를 R 채널로 유지하고, 불투명한 흰 그래픽을 위한 별도 G 채널을 추가한다. 원본 두 장에서 밝기·중성 색·정규화한 경계 위치가 일치하고, 근처에 움직임이 있는 경우에만 더 강한 보호를 검토한다. 추가 보호는 상하좌우의 닫힌 밝은 영역 경계가 두 장에서 일치해야 허용한다. 이동하는 흰 사각형의 윗변만 우연히 일치하는 경우와 밝기가 변하는 그래픽을 거른다. 경계를 찾지 못하면 채택하지 않는다.

새 채널은 같은 원본 색을 가진 밝은 영역 안에서만 확장한다. 원본 좌표 복원과 기존 마스크의 주변 확장에는 전달하지 않고, 최종 색 합성에서만 고정 그래픽의 위치와 그 그래픽에서 잘못 끌려 나온 픽셀을 보호한다. 기존 Newton 경로를 광범위하게 바꾸는 시험에서는 다른 움직이는 글자나 처리 비용에 손해가 생겨 채택하지 않았다.

원본 해상도 마스크 2장이 R8에서 R8G8로 바뀌어 픽셀 수의 약 2배 바이트가 추가된다. F1 시험 해상도 3840×1604에서는 약 12.3MB이다. Cost Map과 Temporal Hints는 꺼져 있으며 ×2, Grid 4, Medium, 최대 긴 변 1920 분석, 세션·6개 입력 버퍼 재사용을 유지한다.

## 검증과 결과

RTX 5090 / 드라이버 617.42에서 디코딩·화면 표시를 제외하고 GPU 완료까지 측정했다.

- 실제 10구간 774쌍 / 출력 1,568장: 모든 원본 출력과 타임스탬프, 장면 전환·반복 판단은 quality.1과 동일했다. Cost 버퍼는 0개였다.
- F1 제목 이외의 9구간: Kokoore 1:20, Jishou 5화 22:59, Jishou 4화 23:24, F1 1:24·1:30·2:10은 바이트 단위로 동일했다. Kokoore 시작은 13개 샘플 최대 1, Jishou 0:51은 792개 최대 2, Jishou 4화 5:20–5:23은 1개 최대 1 코드 값 차이였다. 이 유한한 검사로 다른 모든 영상의 무손실을 증명하지는 않는다.
- F1 제목 구간 평균(첫 5쌍 제외): 2.4759→2.6537ms, +0.1778ms / 약 7.18%. 단일 비교 실행의 편차를 포함하며 플레이어 전체 부하나 RTX 5070의 성능 측정이 아니다.
- F1 제목 95쌍 전체 검사: 밝은 조각 합계 3,735→1,708픽셀. 56쌍 감소, 39쌍 동일, 증가한 쌍 없음. 양쪽 원본에서 같은 밝은 픽셀의 합성 밝기 오차 합도 181,792→174,063으로 감소했으며 악화된 쌍은 없었다. 원본의 고정 글자 증거에 기반한 진단값으로, 정답 중간 프레임 대비 화질 점수가 아니다.
- 밝은 조각 진단은 원본 두 장의 휘도가 같고 218 초과인 픽셀 주변 41×41 범위에서, 원본 양쪽은 160 미만인데 중간 프레임은 205 초과인 픽셀을 센다. 임계값 밖의 왜곡·번짐·시간적 자연스러움은 이 수치로 판단할 수 없다.
- 합성 6장면 / 세 시점: 고정 곡선 그래픽 MSE 13.2959→12.7517, 이동 장면 5개의 보고된 MSE는 동일했다. 원본 변형이나 추가 반복 출력은 없었다.
- 새 stationary_plate 검사는 국소 흐름이 0인 고정 흰 영역을 받아들이고, 움직이는 밝은 사각형·밝기 변화·움직이는 배경을 거부하는지 검사한다. 기존 7개를 포함한 CTest 8개를 통과했다. CPU/NV12·GPU/P010 연결, 시간 간격이 반올림된 입력, 탐색·동시 flush/stop, 100회 초기화를 포함한 GPU 스트레스, 사전 컴파일 시작 검사도 통과했다.

실제 영상의 중간 프레임에는 정답이 없으므로 조각 감소율을 전체 화질 향상률로 해석하지 않는다. 확대 비교에서 코스 밖 조각이 줄었지만 고정 글자 뒤 인물의 왜곡은 남았다. Jishou 머리카락 주변 문제도 여전히 별도 과제다. 최종 체감은 플레이어에서 F1 1:32 부근을 연속 재생해 비교한다.

실제 비교 재현에는 사용자가 별도로 제공한 원본에서 추출한 로컬 fixture가 필요하다. 원본 영상과 캡처는 저장소/패키지에 포함하지 않는다. `tools/compare-quality-trial.py`에서 baseline을 `build/quality1/native/Release/video_x2_repro.exe`, candidate를 `build/overlay1/native/Release/video_x2_repro.exe`로 지정해 10구간의 원본·시간·판단을 비교할 수 있다. 전체 검사 스크립트와 로그, 선택 프레임은 로컬 `build/overlay1`에 보존한다.
