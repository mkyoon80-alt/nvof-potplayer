# 팟플레이어 연결

## 처음 실행

1. 팟플레이어와 NVOF 설정 창을 종료한 뒤 `NvofPotPlayer-0.3.2-rate.1-Setup-x64.exe`를 실행합니다. 설치 위치를 확인하면 현재 사용자용으로 설치하고 필터를 등록합니다. FRUC/CUDA 재배포 전용 동의 화면은 제거됐습니다. 별도 .NET, CUDA Toolkit, Visual C++ 설치는 필요하지 않습니다.
2. 설치 완료 후 **NVOF 설정**을 엽니다. 기본 설치 위치는 `%LOCALAPPDATA%\Programs\NvofPotPlayer`입니다. 팟플레이어도 일반 권한으로 실행하세요. 관리자 권한 팟플레이어는 별도의 관리자용 필터 등록이 필요합니다.
3. 팟플레이어 **F5 → 코덱/필터 → 전역 필터 우선 순위 → 시스템 코덱 추가**에서 **NVIDIA Optical Flow for PotPlayer**를 추가하고 **최우선 사용**을 선택합니다.
4. 다른 보간 필터는 함께 활성화하지 않습니다.

팟플레이어에서 등록한 필터를 더블클릭하고 **설정 창 열기**를 누르면 같은 조작창이 열립니다.

## 내장 디코더와 렌더러

- **코덱/필터 → 비디오 코덱 → 내장 코덱/DXVA 설정**에서 **하드웨어 가속(DXVA)을 사용합니다**를 켭니다.
- **D3D11 DXVA 우선 사용**을 켭니다. 내장 D3D11 렌더러에 한해 사용하는 조건부 상태(■)도 확인된 구성입니다.
- **DXVA2 Copy-Back**은 **사용하지 않음**으로 둡니다.
- 영상 출력 장치는 **내장 Direct3D 11 영상 출력 장치**로 선택합니다.
- VSR을 사용할 경우 팟플레이어의 GPU Super Resolution 설정을 유지합니다.

설정 후 영상을 다시 엽니다. 조작창 진단의 **GPU 메모리로 직접 전달** 표시가 실제 네이티브 경로를 확인하는 기준입니다. 팟플레이어의 H/W 표시만으로 판단하지 마세요. 영상 시작 시 표시가 잠시 S/W였다 바뀌는 경우에도 진단에서 실제 전달 경로를 확인할 수 있습니다.

## 보간 설정

체크한 원본 FPS만 보간합니다. 23.976 / 29.97 / 59.94 fps는 각각 24 / 30 / 60 그룹입니다. 해당하지 않는 FPS는 **기타**에 포함됩니다. 체크를 해제한 영상은 원본 프레임으로 재생합니다.

출력 상한은 기존 **최대 60fps / 최대 120fps** 버튼으로 선택합니다. 상한을 넘지 않는 가장 큰 정수배로 보간하며, 원본보다 낮은 FPS로 줄이지 않습니다. 기본값은 최대 60fps입니다.

| 원본 FPS | 최대 60fps | 최대 120fps |
| --- | --- | --- |
| 23.976 | 47.952 ×2 | 119.880 ×5 |
| 24 | 48 ×2 | 120 ×5 |
| 25 | 50 ×2 | 100 ×4 |
| 29.97 / 30 | 59.94 / 60 ×2 | 119.88 / 120 ×4 |
| 50 | 원본 50 | 100 ×2 |
| 59.94 / 60 | 원본 59.94 / 60 | 119.88 / 120 ×2 |

원본 FPS를 알 수 없거나 상한 안에서 두 배로 늘릴 수 없으면 원본으로 재생하며 이유를 표시합니다. 원본 FPS 체크는 보간할 영상의 선택이고, 출력 상한 버튼은 선택한 영상을 얼마나 늘릴지 정합니다. 이전 TargetFps/DoubleRate 값은 적용하지 않습니다.

**변경은 영상을 다시 열 때 적용됩니다.** 앞뒤 탐색 시 이전 위치의 보간 이력을 버리고 새 위치의 첫 원본 프레임부터 다시 시작합니다. 영상 위에는 자체 상태 표시나 시작 안내를 그리지 않습니다.

## 화질 보정

**화질 보정** 탭은 새 엔진의 자동 보호를 안내합니다. 보간을 켜면 움직임 경계와 고정 글자 보호가 적용됩니다. 이전 두 보정 옵션은 새 엔진에서 사용하지 않습니다.

## 업데이트와 제거

업데이트 전에는 팟플레이어와 조작창을 완전히 종료하고 새 설치 프로그램을 실행합니다. 같은 설치 폴더의 `NvofPotPlayer.ini`는 유지하며 `.bak`으로 한 번 더 보관합니다. 이전 수동 설치가 현재 사용자용으로 등록되어 있으면 기존 INI를 가져옵니다.

제거하려면 팟플레이어에서 필터를 목록에서 빼고 종료한 뒤, NVOF 설정의 **연결 설정 → 프로그램 제거** 또는 Windows 설치된 앱에서 제거하세요. 관리자용 등록은 Windows 권한 승인을 받아 자동 해제합니다. 명령어 입력은 필요하지 않습니다. 사용자 설정은 남고, 예전 버전의 등록을 자동 복원하지 않습니다. 설치 폴더는 연결 설정의 **설치 폴더 열기**로 확인할 수 있습니다.

설치 폴더의 `docs\manual\index.html` 또는 시작 메뉴의 **사용 설명서**에 화면 안내와 문제 해결 방법이 있습니다. 로컬 진단은 `%LOCALAPPDATA%\NvofPotPlayer`에 저장하며 자동 전송하지 않습니다.

## 확인된 범위

Windows 10 x64, RTX 5090, 팟플레이어 x64 내장 디코더·내장 D3D11 렌더러에서 확인했습니다. 검증 범위는 **프로그레시브 BT.709 / 제한 범위 SDR**이며, 8비트 NV12와 10비트 P010 입력을 지원합니다. 10비트 SDR은 별도 옵션 없이 GPU에서 NV12로 변환하며 **출력은 8비트**입니다. HDR 톤매핑, 10비트 출력, 인터레이스, 다중 GPU는 지원 범위 밖입니다. 10비트 영상에서 검은 화면이나 초기 멈춤이 있었다면 beta.1 이상으로 업데이트하고 영상을 다시 여세요.
