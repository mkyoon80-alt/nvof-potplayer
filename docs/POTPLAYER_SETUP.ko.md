# 팟플레이어 연결

## 처음 실행

1. 스탠드얼론 ZIP을 계속 사용할 폴더에 풉니다. `NvofControl.exe`를 열고 **연결 설정 → 필터 등록**을 누릅니다. 실행 파일·필터·런타임 파일을 분리하지 않습니다. 별도 .NET·CUDA Toolkit 설치는 필요하지 않습니다.
2. 팟플레이어는 일반 권한으로 실행하세요. 관리자 권한 팟플레이어에는 관리자용 등록이 필요하며, 연결 설정의 등록 과정에서 Windows 권한 승인을 요청합니다.
3. 팟플레이어 **F5 → 코덱/필터 → 전역 필터 우선 순위 → 시스템 코덱 추가**에서 **NVIDIA Optical Flow for PotPlayer**를 추가하고 **최우선 사용**을 선택합니다.
4. 다른 보간 필터는 함께 활성화하지 않습니다.

팟플레이어에서 등록한 필터를 더블클릭하고 **설정 창 열기**를 누르면 같은 조작창이 열립니다.

## 첫 재생 전: 하드웨어 가속 설정

필터를 등록한 뒤 아래 설정까지 진행하세요. 필터 등록만으로 팟플레이어의 디코더·렌더러 설정이 바뀌지는 않습니다.

- **F5 → 코덱/필터 → 비디오 코덱 → 내장 코덱/DXVA 설정**에서 **하드웨어 가속(DXVA)을 사용합니다**를 켭니다.
- **D3D11 DXVA 우선 사용**을 켭니다. 내장 D3D11 렌더러에 한해 사용하는 조건부 상태(■)도 확인된 구성입니다.
- 아래 확인된 내장 DXVA 구성에서는 **FFmpeg DXVA 디코더 사용**을 끕니다.
- **DXVA2 Copy-Back**은 **사용하지 않음**으로 둡니다.
- **F5 → 영상 → 영상 출력 장치**는 **내장 Direct3D 11 영상 출력 장치**로 선택합니다.
- VSR을 사용할 경우 팟플레이어의 GPU Super Resolution 설정을 유지합니다.

![팟플레이어 내장 비디오 코덱의 하드웨어 가속 설정](https://mkyoon80-alt.github.io/nvof-potplayer/images/potplayer-dxva.png)

[한·영 사용 설명서의 설정 화면과 항목별 안내](https://mkyoon80-alt.github.io/nvof-potplayer/#hardware)에서도 확인할 수 있습니다.

설정 후 영상을 다시 엽니다. 조작창 진단의 **GPU 메모리로 직접 전달** 표시와 팟플레이어 재생 정보의 **Native D3D11 디코더**를 함께 확인합니다. GPU 전달은 CPU 디코딩 뒤 업로드하는 경우에도 사용되므로, 디코딩 방식과 보간 여부를 구분해서 확인하세요. 영상 시작 시 표시가 잠시 S/W였다 바뀌는 경우에도 진단에서 실제 전달 경로를 확인할 수 있습니다.

## 인터레이스 영상: 팟플레이어 디인터레이스 끄기

소프트웨어로 디코딩되는 인터레이스 영상(예: 1080i 10bit)은 **재생 화면 우클릭 → 영상 → 디인터레이스 → 사용하지 않음**으로 설정한 뒤 다시 엽니다.

인터레이스 영상의 홀수 줄과 짝수 줄은 서로 다른 시점의 움직임을 담습니다. 팟플레이어가 먼저 이 줄들을 섞어 한 장으로 만들면 윤곽이 겹치거나 움직임 정보가 줄어 NVOF의 보간이 불규칙해질 수 있습니다. **원본 필드를 받은 NVOF가 GPU에서 디인터레이스한 뒤 보간하도록 맡기는 설정**이며 디인터레이스를 생략하는 것은 아닙니다.

25fps / 초당 50필드 영상은 먼저 50p로 변환하므로 최대 120fps에서 100fps로 출력됩니다. 일반 프로그레시브에는 이 처리가 필요하지 않습니다. NVOF를 해제하고 인터레이스 영상을 볼 때는 팟플레이어를 **자동 판단**으로 되돌리세요.

[설정 화면과 영문 안내](https://mkyoon80-alt.github.io/nvof-potplayer/#deinterlace)

## CPU로 디코딩되는 10bit 영상

H.264 10bit처럼 하드웨어 디코딩이 어려운 영상도 지원되는 P010/P016/P210/Y210으로 전달되면 GPU에서 변환·보간합니다. 팟플레이어의 **S/W**는 CPU 디코딩 표시이며 GPU 보간 여부와는 별개입니다. 내장 D3D11 렌더러를 사용하고 진단에서 **P010 출력과 보간 FPS**를 확인하세요. 출력은 10bit 4:2:0이며 P016은 상위 10bit를 사용합니다.

## 보간 설정

체크한 원본 FPS만 보간합니다. 23.976 / 29.97 / 59.94 fps는 각각 24 / 30 / 60 그룹입니다. 해당하지 않는 FPS는 **기타**에 포함됩니다. 체크를 해제한 영상은 원본 프레임으로 재생합니다.

현재 버전에서는 **출력 방식**과 값을 각각 선택합니다.

- **FPS 상한:** 60 / 72 / 75 / 100 / 120 / 144 / 240fps 중 선택합니다. 상한 안에서 가능한 가장 큰 정수배로 보간하며 원본보다 낮은 FPS로 줄이지 않습니다. 기본값은 최대 60fps입니다.
- **원본 배수:** ×2 / ×3 / ×4 / ×5를 직접 선택합니다. 이 모드에서는 FPS 상한을 적용하지 않습니다. 두 방식의 마지막 선택은 각각 기억합니다.

| 원본 FPS | 최대 60fps | 최대 72fps | 최대 120fps | 최대 240fps | 원본 ×3 |
| --- | --- | --- | --- | --- | --- |
| 23.976 | 47.952 ×2 | 71.928 ×3 | 119.880 ×5 | 239.760 ×10 | 71.928 |
| 24 | 48 ×2 | 72 ×3 | 120 ×5 | 240 ×10 | 72 |
| 25 | 50 ×2 | 50 ×2 | 100 ×4 | 225 ×9 | 75 |
| 30 | 60 ×2 | 60 ×2 | 120 ×4 | 240 ×8 | 90 |
| 50 | 원본 50 | 원본 50 | 100 ×2 | 200 ×4 | 150 |
| 60 | 원본 60 | 원본 60 | 120 ×2 | 240 ×4 | 180 |

상한은 정확한 목표 FPS가 아닙니다. 24fps를 최대 60fps로 설정하면 48fps이며, ×3 또는 최대 72fps를 선택하면 72fps입니다. 30.003fps 같은 미세한 차이는 상한 계산에서 0.1%까지 허용하되 원본 시간은 바꾸지 않습니다. 높은 출력 FPS의 실시간 유지 여부는 해상도와 GPU 성능에 따라 달라집니다.

원본 FPS를 알 수 없거나 상한 안에서 두 배로 늘릴 수 없으면 원본으로 재생하며 이유를 표시합니다. **세로 해상도**는 전체 / 1080p 이하 / 1440p 이하 중 선택합니다. 원본 FPS·해상도 조건과 보간 끄기는 두 출력 방식 모두에 적용됩니다.

**변경은 영상을 다시 열 때 적용됩니다.** 앞뒤 탐색 시 이전 위치의 보간 이력을 버리고 새 위치의 첫 원본 프레임부터 다시 시작합니다. 영상 위에는 자체 상태 표시나 시작 안내를 그리지 않습니다.

## 10bit·HDR 확인

10bit SDR·HDR10·HLG는 별도 보정 스위치 없이 P010으로 처리합니다. 하드웨어 디코딩 영상에는 네이티브 D3D11 경로를 권장하며, 지원되는 CPU 10bit 입력도 GPU에서 보간할 수 있습니다. 진단에서 입력·출력 **P010 · 10bit**와 색 형식 **SDR / HDR10 / HLG**를 확인합니다. 진단의 색 형식은 전달된 신호이며 모니터가 HDR 모드로 전환됐다는 뜻은 아닙니다. 플레이어와 Windows의 HDR 출력 설정은 별도로 확인하세요. 필터는 톤매핑하지 않습니다.

## 업데이트·이동·제거

v0.3.0 등 설치 프로그램 버전에서 전환할 때는 팟플레이어와 설정창을 닫고 `NvofPotPlayer.ini`를 백업합니다. Windows **설치된 앱**에서 이전 버전을 제거한 뒤 새 ZIP을 별도 폴더에 풉니다. 필요한 설정을 복원하고 새 폴더의 필터를 등록한 다음 팟플레이어의 필터 선택·최우선 사용을 다시 확인하세요. 관리자용 등록이 있으면 제거 과정의 Windows 권한 승인을 허용합니다.

스탠드얼론 업데이트 전 팟플레이어와 설정창을 닫고 기존 폴더·설정을 백업합니다. 같은 폴더를 교체할 때 `NvofPotPlayer.ini`를 보존하세요.

폴더 이동이나 삭제 전에는 팟플레이어를 종료하고 **연결 설정 → 필터 등록 해제**를 누릅니다. 관리자용 등록이 있으면 Windows 권한 승인을 요청해 함께 해제합니다. 다른 폴더의 등록은 건드리지 않습니다. 성공을 확인한 뒤 설정창을 닫고 폴더를 이동·삭제하세요. 이동했다면 새 위치에서 다시 등록합니다. 위치는 **현재 폴더 열기**로 확인합니다.

기존 설치 프로그램으로 설치한 폴더에서는 **프로그램 제거**도 표시됩니다. 시작 메뉴나 Windows 설치된 앱으로 제거할 수도 있습니다. 스탠드얼론 ZIP에는 제거 프로그램이 없으므로 해당 버튼을 숨깁니다.

현재 폴더의 `docs/manual/index.html`에 설명서가 있습니다. 진단은 `%LOCALAPPDATA%\NvofPotPlayer`에 저장하며 자동 전송하지 않습니다.

## 확인된 범위

Windows 10 x64, RTX 5090, 팟플레이어 내장 디코더·D3D11 렌더러에서 검증했습니다. 10bit 프로그레시브 CPU 입력, 1080i 인터레이스의 GPU 처리, HDR10 파일과 YouTube AV1·VP9 HDR의 정상 색상 재생을 확인했습니다. HEVC HLG는 실제 재생과 신호 전달을 확인했으며 별도의 화면 색상 비교는 남아 있습니다.

Dolby Vision은 디코더가 제공하는 메타데이터를 전달합니다. Profile 8.1에서 확인했으며 모든 프로파일·화면 출력을 보장하지 않습니다. HDR10+ 동적 메타데이터, 일반 텔레시네·단일 필드·반복 필드, 다중 GPU 구성은 검증 범위 밖입니다. 최근 탐색 직후 빗살 수정은 재현 검사로 확인했으며 실제 재생 확인은 추가로 필요합니다.
