# Flow Grid·Preset·분석 해상도 시험 — 0.3.1-flow.1

2026-10-10 로컬 시험. 설치 기본값은 **Newton, Cost Map 생성·적용 OFF, Grid 4 우선, Medium, 최대 긴 변 1920**이다. Grid 4 미지원 장치에는 기존 2→1 지원값 선택을 유지한다. 개발 시험에서 명시한 Grid는 지원되지 않으면 오류로 종료하며 다른 값으로 바꾸지 않는다.

## 변경

- 기본 모드에서 Cost 포맷 조회, GPU Cost 텍스처 할당·등록, NVOFA 출력 요청을 모두 생략한다. 역좌표 계산에는 미리 컴파일한 no-cost 셰이더를 사용한다.
- Cost.1/Cost.2 실험 코드는 개발 API에서만 명시적으로 사용할 수 있다. CPU 입력 어댑터와 GPU 필터 모두 기본 no-cost 경로다.
- Grid 4/2/1과 Medium/Slow를 재빌드 없이 비교할 수 있는 개발용 인수를 추가했다. 사용자 설정 화면에는 검증되지 않은 옵션을 추가하지 않았다.
- 실제 분석 크기·Grid·등록 Cost 버퍼 수와 GPU 완료까지 걸린 시간을 시험 로그에 기록한다.
- Newton 단계, 후보 검색, 보정·보호 조건, 출력 프레임 시각은 이번 시험에서 변경하지 않았다.

## 방법과 한계

RTX 5090, 드라이버 617.42. 같은 영상·같은 합성 로직에서 먼저 1920/Medium의 Grid 4→2→1, 이후 Grid 4의 Medium→Slow, 마지막으로 Grid 4/Medium의 분석 긴 변 1920→3840을 비교했다. 균형과 기존 구간의 퇴행을 고려해 두 번째 단계의 기준을 Grid 4로 골랐다.

실제 영상은 Kokoore 1:20, Jishou 5화 22:59, Jishou 4화 5:20–5:23, F1 타이틀, F1 1:30·2:10 원본 프레임 재구성이다. 재구성은 원본을 한 장씩 제외하고 그 시점의 원본과 비교하므로 일반 ×2 재생보다 원본 사이 간격이 크다. 같은 개발 영상을 다시 사용했으며 독립적인 새 영상 평가는 아니다.

4K 시험의 실제 영상 크기는 **3840×1604**이고 축소 분석 크기는 **1920×802**다. 1080p 원본을 4K로 확대하지 않았다. 현재 구조에서는 분석 해상도를 올리면 광학흐름 입력뿐 아니라 역좌표 맵도 커진다.

시간은 원본 한 쌍에서 중간 프레임을 만드는 호출 시작부터 GPU 완료까지다. 초기 한 쌍을 제외했으며 디코딩·화면 표시·파일 입출력은 제외한다. 순차로 한 번씩 측정한 개발용 수치로, NVOFA 단독 시간이나 RTX 5070의 4K60→120 달성 수치가 아니다. 첫 쌍은 약 29–52ms였다.

## 처리시간

모든 조합이 같은 원본·시각을 보존했다. 모든 시험의 등록 Cost 버퍼 수는 0이었다.

|---|---:|---:|
| 4 / Medium / 1920 | 4.47 / 5.07ms | 4.66 / 5.25ms |

| 1 / Medium / 1920 | 29.53 / 36.06ms | 46.77 / 56.02ms |
| 4 / Slow / 1920 | 5.76 / 6.61ms | 6.59 / 7.34ms |

이 시간에는 촘촘해진 벡터 격자에서 실행하는 자체 보정 비용도 포함된다. Grid 1의 수치가 NVIDIA 엔진 자체의 고정 비용이라고 해석하면 안 된다.

## 품질

### 정확한 중간 정답이 있는 합성 시험

각 장면 8쌍×3시점. 낮은 MSE가 좋다.

| 장면 | Grid 4 Medium | Grid 2 Medium | Grid 1 Medium | Grid 4 Slow |
|---|---:|---:|---:|---:|
| 고정 곡선 타이틀 + 움직이는 배경 | 13.7042 | 17.6063 | 17.3291 | 14.3151 |
| 반복 수직선 이동 | 110.278 | 112.778 | 57.9448 | 70.7617 |
| 밝은 물체 이동 | 41.4694 | 37.4251 | 33.7011 | 58.1190 |
| 얇은 곡선 이동 | 424.113 | 395.833 | 150.638 | 507.021 |
| 글자 형태 이동 | 252.470 | **672.902** | **7.57665** | **16.1765** |
| 곡선 물체의 가림 | 28.0636 | 19.1148 | 14.6420 | 21.8671 |

Grid 1은 여러 합성 장면에서 분명히 좋았다. Grid 2는 글자 이동 품질 기준을 통과하지 못했다. 실패를 숨기지 않고 나머지 장면도 측정했으며 기본 Grid 4 시험은 모두 통과했다.

### 실제 F1 원본 재구성

각 구간 31개 빠진 원본의 밝기 MAE. 보호 로직이 원본을 반복한 결과도 포함한다.

| 설정 | F1 1:30 MAE | F1 2:10 MAE | 2:10 원본 반복 쌍 |
|---|---:|---:|---:|
| 4 / Medium / 1920 | 1.851258 | 2.983208 | 4/31 |
| 2 / Medium / 1920 | 1.837418 | 3.159594 | 4/31 |
| 1 / Medium / 1920 | 1.870761 | 4.448561 | 9/31 |
| 4 / Slow / 1920 | 1.848959 | 3.835730 | 7/31 |
| 4 / Medium / 3840 | 1.854769 | 5.132966 | 11/31 |

반복 횟수가 같은 Grid 2와 Grid 4도 반복한 원본 쌍의 위치가 다르다. 전체 오차만으로 촘촘한 Grid의 광학흐름 자체가 더 나쁘다고 결론 내릴 수 없다.

두 설정 모두 실제로 합성한 쌍만 비교하면 F1 2:10에서 Grid 2는 1.6253→1.5920(26쌍), Slow는 1.5393→1.5092(24쌍), Grid 1은 1.4491→1.4438(22쌍)로 소폭 개선했다. 3840 분석은 1.3255→1.3309(20쌍)로 소폭 나빠졌다. 비교마다 공통 쌍이 다르므로 이 네 수치끼리 순위를 매기면 안 된다.

윤곽 지표도 섞인 결과다. F1 1:30의 Laplacian MSE는 기본 6.1450, Grid 2 7.3740, Grid 1 7.7517, Slow 5.7732, 3840 분석 18.8020이었다.

일반 ×2 영상에서 Kokoore의 원본 반복 쌍은 기본 18/71, Grid 2 22/71, Grid 1 25/71, Slow 24/71이다. Jishou 4화는 기본 10/143에서 Slow 14/143으로 늘었다. 동일 원본 생략·장면 전환 횟수는 해당 비교에서 바뀌지 않았다.

### 눈으로 본 문제 구간

Jishou 4화의 머리카락 내부와 외곽은 설정별 차이가 있지만 이중 선과 경계 찌꺼기가 모두 남는다. F1 타이틀도 Grid·Preset·해상도 변경만으로 해결됐다고 판단할 만큼의 차이는 확인하지 못했다. 정지 비교 이미지 확인이며 사용자 재생 감상과 동일한 평가는 아니다.

## 결론과 다음 후보

기본값은 **Grid 4 / Medium / 1920**을 유지한다. Cost Map은 생성과 적용 모두 끈다. 이는 Grid 1이나 Slow의 잠재력이 없다는 뜻이 아니라, 지금의 보정·보호 로직과 실시간 처리 목표를 함께 고려한 선택이다.

다음 단계는 Grid 1의 자체 보정 비용을 줄이고, 촘촘한 벡터/Slow에서 기존 보호 로직이 원본 반복을 선택하는 원인을 분리하는 것이다. 반복을 줄이려고 임계값부터 완화하면 기존 얼굴·가림 깨짐을 다시 허용할 수 있으므로 원인별 근거가 먼저 필요하다.

## 검증·재현

- 기본 설정: 6개 핵심 테스트, CPU NV12 입력·GPU 합성·출력, NV12 CPU/GPU DirectShow 및 GPU P010, seek·flush·EOS·종료 통과.
- no-cost 경로의 실행·리셋 후 Cost 버퍼 0개 확인. 기존 Cost 실험의 명시적 활성화·신뢰도 검사도 통과.
- 10초 동시 접근 시험: 494쌍, 리셋 100회, 재생성 4회, 렌더러 접근 158975회 통과.
- 결과: build/flow1/summary.json, clips/*/*/metrics.json, pairs.csv, layers*.log, validation-final.log.
- 실제 영상과 큰 raw 출력은 Git에 넣지 않는다. 새 raw 출력은 지표·원본·시각 검증 후 삭제하고 작은 비교 이미지와 선택 프레임만 보존했다.
- 시험 실행: tools/run-flow-profile-trial.ps1. 기존 로컬 build/native-synthesis와 build/cost1/clips의 원본 fixture를 요구한다. 저장소에 영상은 포함되지 않는다.
- 개발 harness 인수: video_x2_repro.exe <runtime-placeholder> <raw> <times> <output> native <duration-100ns> <nv12|p010> <width> <height> <max-flow-dimension> 0 <4|2|1> <medium|slow>.
